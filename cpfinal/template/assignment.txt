Your Assignment:
Implement two template functions as follows:

In the file templaterotate.h, implement

rotateRight(a,b,c) (2 points)

This function assigns the value of a to b, the value of b to c, and the value of c to a.

In the file templatemax.h, implement

max(a,b,c) (2 points)

This function returns the biggest of the three values of a, b, and c. The catch: this function must also work for types that can be compared exclusively via the < operator. Read: use only the < operator, otherwise it will not work.
