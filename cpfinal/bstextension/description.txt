Your Assignment:
You will see two header files, namely bstCount.h and bstLargest.h. They are two identical copies of each other. You are supposed to use the respective file for the function you are going to implement. (This setup separates your codes, so a mistake in one of them will not harm the other one.)

In the header files, you find a correctly working implementation of a binary search tree (BST) that stores key-value pairs, with keys being of type int and values are std::string. Your task is to add functionality for two of its interface functions, as follows: (All details are in the header files.)

count() (4 points) Implement this function such that it returns the number of key-value pairs stored in the BST.

largestKey() (4 points) Implement this function such that it returns the largest key stored in the BST, or throws the prescribed exception if the BST is empty.
